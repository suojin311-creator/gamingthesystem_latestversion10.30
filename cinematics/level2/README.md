`Mg614/gaming-the-system@c8c1c83456c4e67cf627df399bfb67b3a9792adb`.

gameplay rules. Prepare through `scripts/level2-film.mjs`, using
LEVEL2_ANIMATION_SOURCE on the first build. Verified cache is retained under
ignored node_modules/.cache/level2-cinematic and embedded in offline game HTML.

completed-requirements line. The final slot starts on the Criterion 66 pen insert,

not played; nonverbal holds are shortened.

checklist text is an explicit exception to overlay removal. Palette, reading time, fixed camera
follow the shared Level 1 presentation. Internal joins now use the shared soft
cross-dissolve, preserving the caption/portrait synchronization.

once. The existing game instance remains mounted; its name, selection, sound
preference and next-level handoff remain in game memory. The film is silent
because the partner delivery contains no audio sources.
