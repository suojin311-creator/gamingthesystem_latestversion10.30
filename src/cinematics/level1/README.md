# Integrated Level 1 cinematic

LevelOneCinematic receives the selected metric and the opening's confirmed name
through the existing renderer contract. It uses one isolated, self-contained
iframe; source/run-token checks accept the real player's completion only once.

Prepare the film through `npm run cinematic:prepare` with
LEVEL1_ANIMATION_SOURCE pointing at the pinned, read-only partner delivery.
The ignored cache is fingerprinted against the presentation scripts and shared
speaker palette. Subsequent development and release builds reuse that cache;
all downloadable game HTMLs embed the film and run offline.

`src/levels/level1/LevelOneExperience.tsx` is the common entry for approved Level 1
presentation. The connected game continues from its settlement into Level 2;
standalone reviews offer Try another metric. There is one LevelOne rules/state
implementation and no copy of the partner's source tree in this folder.
